# 📝 To-Do List

Görevlerini ekleyip, tamamlandı olarak işaretleyip silebildiğin basit bir yapılacaklar listesi uygulaması.

## 🔗 Canlı Demo
[Projeyi görüntüle](buraya-link) *(GitHub Pages ile yayınlayabilirsin)*

## 📸 Ekran Görüntüsü
![Uygulama ekran görüntüsü](screenshot.png)

## ✨ Özellikler
- Yeni görev ekleme
- Görevi tamamlandı olarak işaretleme
- Görev silme
- (varsa) Verilerin localStorage'da saklanması

## 🛠️ Kullanılan Teknolojiler
- HTML
- CSS
- JavaScript

## 🚀 Kurulum
1. Repoyu klonla:
```bash
   git clone https://github.com/kullanici-adin/todo-list.git
```
2. Klasöre gir ve `index.html` dosyasını tarayıcıda aç.

## 📚 Neler Öğrendim
- DOM manipülasyonu
- Event listener kullanımı
- localStorage ile veri saklama
